Analisa Pintar MR ALL
Analisa ini berjalan dari data di aplikasi secara lokal. Ini bukan koneksi AI cloud; sarannya dibuat otomatis berdasarkan pola pemasukan, pengeluaran, profit, stok, tabungan, dan WD.
Prioritas yang disarankan
Pengaturan Alarm
Alarm ini hanya memberi peringatan/saran. Sistem tidak memindahkan uang atau mengubah harga otomatis.
Backup & keamanan data
Data disimpan di browser/device ini.
Gunakan backup rutin supaya data aman kalau browser dihapus, HP berganti, atau data hilang.
Catatan penting
Backup otomatis ke Google Drive belum aktif di file lokal ini. Drive otomatis membutuhkan koneksi Google + izin akun/API; V3 tetap bisa backup/restore satu klik tanpa biaya bulanan dari aplikasi HTML-nya.
Catat barang
Barang biasa masuk sini. Setelah READY, cukup klik SOLD di baris barang — tidak perlu input ulang. HDD non-garansi tetap masuk sini. Kalau HDD memang dijual dengan garansi, gunakan menu Garansi HDD.
